# Tripwire Bench · 踩雷榜

量化交易系统 coding benchmark：哪个模型最适合写交易系统。

网站：https://liuyejinghong.github.io/tripwire-bench-site/

本仓库只放生成好的网站页面。题目、隐藏测试与评分材料不公开，避免进入训练数据或被针对性优化。

## 贡献题目

欢迎提交量化交易领域的脱敏实战题目：

1. 在本仓库开一个 issue（选“题目投稿登记”），用一句话写明题材，不要贴题目内容。
2. 把题目材料放进你自己的私有仓库，邀请 [@liuyejinghong](https://github.com/liuyejinghong) 为协作者。

收题要求见网站的“贡献题目”页。

A coding benchmark for quantitative trading systems: which model is best at building and maintaining them. This repository only hosts the generated site. Tasks and grading material stay private. To contribute a sanitized real-world task, open a "Task proposal" issue with a one-sentence topic, then share the material in your own private repository and invite @liuyejinghong as a collaborator.
